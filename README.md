Это мое первое приложение, созданное для проведения виртуальных лабораторных работ по физике. Оно может помочь, когда нужного оборудования нет под рукой. Приложение весит немного, не нагружает устройство ввиду отсутствия фоновой активности и сложных анимаций. Сейчас оно находится в разработке, поэтому некоторые кнопки могут не работать. В будущем планируется добавить два других раздела: Работа с графиками и механика.
